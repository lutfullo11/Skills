# Материалы и права

Учебные объяснения, задания, словарные определения и ветви диалогов созданы для этого проекта. Уроки, иллюстрации и записи других языковых приложений не скопированы. Ссылки в RESEARCH.md — исследовательские источники, не включённые в APK чужие учебные материалы.

Шрифты — системные Android. Значок — собственный вектор, компоненты — Jetpack Compose/Material. Звук создаётся установленным системным движком TTS; приложением не поставляются сторонние голосовые файлы. Условия движка определяет его поставщик. Пользовательские записи принадлежат записавшему их пользователю и хранятся локально.

Зависимости AndroidX и Kotlin используются по их лицензиям. Включён Gradle Wrapper и стандартные скрипты Gradle (Apache License 2.0); сведения сохранены в скриптах. Ключей внешних API в проекте нет.

Содержимое не проходило профессиональное рецензирование преподавателем РКИ. Данные тестов и самостоятельная проверка написания не должны описываться как такая экспертиза.
