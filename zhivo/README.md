# Живо — русский для вашей жизни

Новое нативное Android-приложение на Kotlin и Jetpack Compose. Локальные занятия без регистрации, офлайн-курс, разбор ошибок, повторение, запись речи, словарь и подготовленные диалоги. Создано с нуля: исходники прежнего приложения не найдены, доступ к его данным и подписи отсутствует.

## Установка и обновление

Требуется Android 8.0+ (API 26); `compileSdk/targetSdk 36` для Android 16. Основной целевой телефон — Poco X6 Pro. APK — **debug**, подписан Android debug-ключом, не production-релиз.

1. Скачайте `Zhivo-1.0-debug.apk` из приложенного файла или артефакта `Zhivo-debug-APK` успешного GitHub Actions. Артефакты хранятся 30 дней.
2. Если скачан ZIP артефакта, распакуйте и откройте APK. При необходимости разрешите установку для браузера или файлового менеджера. После установки это разрешение можно отключить.
3. Запустите «Живо», выберите родной язык, цель, время и старт. Диагностика необязательна и не подтверждает CEFR или ТРКИ.
4. В настройках синтеза речи Android установите русский офлайн-голос. На HyperOS название раздела зависит от версии. «Профиль → Настроить русский голос» открывает соответствующий системный экран, если он доступен.

Новый идентификатор приложения: `ru.zhivo.study`; название — «Живо». Совместимость обновления старого неизвестного APK не обещается. Для сохранения старого прогресса нужен его экспорт или исходный формат данных и ключ подписи. **Не удаляйте старую версию ради этой установки**, пока не сохраните её данные. Новая версия не читает закрытые данные других приложений.

При последующих обновлениях этой версии сначала экспортируйте прогресс. GitHub Actions сохраняет debug-keystore через `actions/cache`; кэш может быть очищен или вытеснен. Если ключ изменится, Android не примет обновление поверх старой установки: экспортируйте JSON, установите APK с новой подписью после удаления прежней версии и восстановите файл. Голосовые записи в JSON не входят. Для стабильного распространения нужен отдельный приватный release-keystore владельца через GitHub Secrets; ключ в репозиторий не добавлен.

## Как заниматься

- **Сегодня** — цель, текущая неделя, следующий шаг и продолжение прерванного урока.
- **Курс** — открытый маршрут; любой этап можно выбрать. Сначала объяснение и примеры, затем 9 заданий: выбор, форма, порядок слов, слух, диктант, пары, исправление, чтение, запись речи.
- **Практика** — повторение по сроку, работа над ошибками, разговорные ситуации и собственные записи. Ошибки не исчезают из истории, а их материал повторяется чаще.
- **Слова** — изученные, избранные, весь словарь и свои карточки. Поиск без знаков ударения. Свои слова можно удалить с подтверждением.
- **Профиль** — цель, темы, нагрузка, оформление, навыки, голос, напоминания и копии данных.

Ответы проверяются по допустимым вариантам с нормализацией регистра, пробелов и обычной пунктуации. Ё сохраняется в заданиях на различие Е/Ё; Й всегда различается. Свободный правильный синоним, не внесённый автором, может быть не распознан: откройте разбор. Здесь нет генеративной проверки произвольного текста.

После ошибки есть объяснение и повторная попытка. «Показать ответ» лишает самостоятельного зачёта; «Пропустить» не начисляет правильный ответ. Открытый текст аудио отключает оценку аудирования. Речь оценивается самостоятельно: совпадение распознанных слов не означает правильное произношение.

Отдельно хранятся просмотр урока, завершение заданий и подтверждение повторением. После трёх разных самостоятельных повторных проверок заданий спустя сутки урок отмечается закреплённым. Это внутренний показатель. Дневное время измеряется, пока открыт урок/повторение/диалог/диагностика; при сворачивании оно останавливается. Открытый экран сам по себе не доказывает усвоения.

## Аудио, микрофон и офлайн

Озвучивание — **синтез речи Android**, не запись носителя. Есть повтор, пауза и скорость 0,75/1/1,25. При недоступном голосе показывается ошибка. Контекст и качество голоса влияют на ударение; омографы нужно сверять со знаками в примере. Сетевой голос по умолчанию запрещён внутри выбора голоса; разрешение включается отдельно и может передавать текст его поставщику.

Микрофон запрашивается только по кнопке записи. Запись локальная AAC, до 2 минут; хранятся последние 20. При сворачивании она останавливается. Отказ от микрофона не блокирует курс. Разрешение можно отозвать в системных настройках приложения.

Внешний сервис распознавания открывается только после пояснения. Запрошено предпочтение офлайн, но поставщик может использовать сеть. Голос может передаваться этому сервису. Распознанный текст показан как текст, без балла произношения. Можно пользоваться записью, вообще не открывая распознавание.

Все уроки, тексты, диалоги и словарь входят в APK. Сети для них не требуется. Кэш синтеза ограничивается примерно 64 МБ, очищается отдельно от записей. Нет фиктивного backend, облачной учётной записи, обязательного API-ключа и платного ИИ.

## Данные и копии

SQLite, транзакционная запись состояния после действия, сохранение текущего задания и ответа. Черновик сохраняется с задержкой 400 мс. Схема SQLite v3 (JSON v2); проверена миграция созданного нами формата v1/v2 без очистки таблицы состояния. Состояние записывается UTF-8 блоками по 64 КБ, чтобы большой словарь и история не превышали предел строки CursorWindow. Это не миграция старого неизвестного приложения.

«Профиль → Экспортировать» открывает системный выбор файла. JSON содержит профиль, результаты, словарь, ошибки, повторения, даты и место остановки. Файл не зашифрован: выбирайте доверенное место. Записи голоса не входят. Даты сохраняются UTC, статистика рассчитывается в текущем часовом поясе.

Восстановление сначала проверяет формат, версию, размер до 32 МБ и ссылки на существующий курс; затем показывает подтверждение замены. Повреждённый файл не заменяет данные. В базе остаются две предыдущие копии состояния перед импортом для технического восстановления; кнопка удаления всех данных очищает и их. Автоматическое системное облачное резервирование выключено, используйте экспорт.

Удаление всех данных требует подтверждения и удаляет также местные голосовые записи. Уже экспортированные пользовательские файлы приложение не удаляет.

## Напоминания и остановка

Напоминания добровольные, требуют разрешения уведомлений Android 13+. Используется неточное местное окно AlarmManager, без разрешения точных будильников. HyperOS может задерживать доставку. После перезапуска телефона или изменения часового пояса откройте приложение для пересчёта расписания. Выключение напоминаний отменяет ожидающую задачу.

Аудио и микрофон прекращаются при уходе с экрана/сворачивании. Длительных фоновых задач, скрытого прослушивания и foreground service нет. Закрытие приложения не сбрасывает учебный прогресс.

## Если что-то не работает

- **Нет звука**: проверьте мультимедийную громкость, установите русский офлайн-голос, откройте его настройки из профиля. Синтез ожидается до 30 секунд, затем покажет ошибку. Текстовые задания доступны всегда.
- **Не записывается голос**: разрешите микрофон для «Живо», проверьте системный переключатель микрофона и не записывает ли другое приложение. Очень короткий файл может не сохраниться.
- **Нет распознавания**: на устройстве может не быть подходящего сервиса. Это не мешает собственной записи и остальным занятиям.
- **Нет напоминания**: проверьте системные уведомления, откройте приложение после перезагрузки, учтите задержку энергосбережения. Точное время не гарантировано.
- **APK не обновляет установленный**: вероятно, отличается пакет или подпись. Сохраните данные; не удаляйте старое приложение без копии.
- **Ответ не принят**: проверьте окончание и цель задания. Допустимые варианты ограничены; разбор не является универсальной оценкой всей русской речи.

## Сборка и проверки

JDK 17; Android SDK 36, Build Tools 36.0.0; AGP 8.10.1; Gradle Wrapper 8.13 с SHA-256; Kotlin/Compose compiler 2.2.21. Нужны Python 3 только для проверки/пересборки авторского JSON и установленные компоненты SDK.

```sh
cd zhivo
python3 scripts/build_course.py --check
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
python3 scripts/check_apk.py app/build/outputs/apk/debug/app-debug.apk
```

При изменении материалов сначала `python3 scripts/build_course.py`, затем проверки. Исходные тексты в `content/`; `course.json` включён для сборки без запуска Python из Gradle. Unit-тесты проверяют и структуру курса.

Workflow в корне репозитория `.github/workflows/zhivo-android.yml`: push/ручной запуск, unit-тесты, lint, debug APK, проверка подписи и упаковки, отдельный Android 16 emulator job с SQLite и UI-тестами. Артефакты 30 дней. Локальный APK: `app/build/outputs/apk/debug/app-debug.apk`.

Автоматическая сборка и эмулятор **не доказывают** работу микрофона, русского голоса и особенностей HyperOS на Poco. Контрольный список физической проверки — в `docs/VALIDATION.md`.
